# RESTworld AI plugin

Agent skills for developers who build applications **with** [RESTworld](https://github.com/wertzui/RESTworld).

This repository is generated from [`plugins/restworld`](https://github.com/wertzui/RESTworld/tree/main/plugins/restworld) in the RESTworld repository. Do not edit it here; open issues and pull requests in the RESTworld repository.

## Install

GitHub Copilot CLI:

```shell
copilot plugin marketplace add wertzui/RESTworld-AI-plugin
copilot plugin install restworld@restworld
```

VS Code: add `wertzui/RESTworld-AI-plugin` to the `chat.plugins.marketplaces` setting, then install `restworld` from the Plugins view.

See [Using RESTworld with AI agents](https://github.com/wertzui/RESTworld/blob/main/doc/ai-agents.md) for details and the [How-To Cookbook](https://github.com/wertzui/RESTworld/blob/main/doc/how-to.md) for the list of skills.
